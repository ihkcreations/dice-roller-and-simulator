# Dice Roller And Simulator

This application simulates rolling customizable dice configurations with animations and statistical probability charts.

## Overview

The application calculates random outcomes based on selected dice parameters and modifiers. It animates virtual cubes using CSS transforms and aggregates Monte Carlo simulation data into visual frequency charts.

## Highlights

- Configure custom dice types and quantities
- Animated 3D roll effect on each action
- Detailed roll history log and totals
- Run mass simulations to visualize probability
